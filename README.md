# NVDA Review-Now Dashboard

A single-file dashboard (`index.html`) that watches Nvidia (NVDA) and related tickers and prompts a human review when preset conditions line up. It does not place trades and is not financial advice.

- Keyless feeds: Yahoo Finance, Nasdaq.com, Stooq, SEC EDGAR, Nvidia Newsroom, CNBC and Google News RSS (direct first, then public CORS proxies).
- Optional keys (stored only in the browser): Finnhub, Twelve Data, Financial Modeling Prep, Alpha Vantage, NewsAPI.
- Use **Test connections** to see which sources your browser can reach.

To serve it: Settings → Pages → Deploy from branch → `main` / root.
